## Featured Projects

### [SEC Filing RAG — Local AI for Financial Research](https://github.com/Mahant-Akash/SEC-Filing-RAG-Local-AI-for-Financial-Research)
A fully local RAG pipeline for querying multi-year SEC filings (10-K, 10-Q, 8-K) using open-source LLMs. No cloud, no API costs, source-cited answers.

- **Stack:** Python · LangChain · ChromaDB · Ollama · nomic-embed-text-v2-moe · edgartools · BeautifulSoup
- Dual-path architecture: RAG for narrative queries, direct XBRL parsing for structured financial data
- OpenClaw agent integration for conversational querying across filing corpus
- Runs fully on-device (tested on RTX 5060 Ti 16GB)
