## Featured Projects

### [SEC Filing RAG: Local AI for Financial Research](https://github.com/Mahant-Akash/SEC-Filing-RAG-Local-AI-for-Financial-Research)

A locally run retrieval-augmented generation (RAG) pipeline for querying multi-year SEC filings, including 10-K, 10-Q, and 8-K reports.

- **Stack:** Python, LangChain, ChromaDB, Ollama, edgartools, BeautifulSoup
- Combines document retrieval for narrative questions with XBRL parsing for structured financial data.
- Supports source-grounded financial research without relying on paid cloud LLM APIs.
- Designed to run locally on an RTX 5060 Ti with 16 GB VRAM.

---

### [Reversal Trading Strategy: S&P 500 Backtest](https://github.com/Mahant-Akash/Reversal-Strategy)

A quantitative research project testing a quarterly reversal strategy across 50 S&P 500 constituents over five years.

- **Stack:** Python, Pandas, NumPy, Matplotlib
- Reported 16.67% cumulative return in the historical backtest.
- Includes performance attribution and drawdown analysis.

---

### [Machine Learning Stock Selection](https://github.com/Mahant-Akash)

A machine learning project exploring signal-based stock selection and portfolio construction.

- **Stack:** Python, Scikit-learn, Pandas, NumPy
- Uses a Random Forest classifier to generate stock-selection signals.
- Combines model outputs with mean-variance portfolio optimization.
- Previously reported a 15% accuracy improvement over baseline and a 7.13% return on paper trades. See the project documentation for methodology and performance assumptions.

---

### [DCF Model: Apple Inc.](https://github.com/Mahant-Akash/DCF-Model)

A discounted cash flow valuation model using Bloomberg Terminal data to estimate Apple's intrinsic value.

- Incorporates revenue growth assumptions and multi-scenario valuation analysis.
- Uses terminal value sensitivity analysis to assess valuation outcomes.
- The original model indicated approximately 7% intrinsic value upside under its assumptions.
